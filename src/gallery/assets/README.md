# Escultura de Estudio digital

`studio-sculpture.webp` es la pieza original de portada (1536 × 1024, transparencia, aproximadamente 175 kB). Se generó con la herramienta integrada de generación de imágenes y se convirtió a WebP para la web. El PNG original se conserva fuera del repositorio.

La dirección visual toma como referencia la escala tipográfica, el espacio y el movimiento de [Lusion](https://lusion.co/); la escultura, el contenido y las vistas de los proyectos son propios. La escultura es una imagen con parallax, no una escena WebGL interactiva. Los movimientos se implementan con CSS y se pueden pausar.
